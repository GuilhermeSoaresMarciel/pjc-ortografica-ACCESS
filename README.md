# pjc-ortografica-ACCESS
(ACCESS) O PJC Ortográfica foi criado para facilitar a criação de vistas ortográficas, proporcionando mais praticidade e melhorando a aprendizagem.

# Developed by: Guilherme Soares

# Sobre nós

O PJC Ortográfica nasceu da dificuldade que muitos estudantes e profissionais têm ao transformar uma peça em vistas ortográficas: alinhar as vistas, manter as proporções e seguir a norma ao mesmo tempo.
Nosso objetivo é tirar o trabalho repetitivo do caminho para que você foque no que importa: entender a peça e representá-la corretamente.
